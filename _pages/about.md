김기홍(Roy), [알파코드](https://alphacode.ai/ko)에서 AI 모델을 실제 제품과 서비스에 연결하는 **AI Product Engineer**로 일하고 있습니다. 알파코드는 Cloud MSP 기업 [메가존클라우드](https://www.megazone.com/)에서 분리된 AI 소프트웨어 회사입니다.

생성형 비디오, 모바일 실시간 AI inference, 얼굴인식 하드웨어 제품화, IoT WebRTC 연동까지 모델 적용부터 API 서버, 앱, 디바이스 통합까지 수행해왔습니다. 빠르게 변하는 모델과 제품 요구사항 사이에서 실험을 운영 가능한 구조로 전환하고, 성능과 안정성을 개선하는 문제 해결에 강점이 있습니다.

현재는 이 경험을 바탕으로 **RAG 기반 챗봇과 AI Agent 시스템**을 제품 수준으로 구현하는 일에 집중하고 있습니다.

- **GenAI 서비스 구현** — 생성형 모델 추론, 프롬프트 생성, 영상 생성, MP4 변환까지 이어지는 서비스 워크플로우 구현
- **Mobile / Edge AI** — Kotlin/Swift 기반 모바일 앱에 TFLite 비전 모델을 적용해 실시간 온디바이스 추론 기능 구현
- **Backend / Data Pipeline** — FastAPI/Go 기반 API 서버, 모델 호출 게이트웨이, MongoDB/GCP 기반 데이터 처리 및 학습 데이터 구축 자동화
- **PoC 구현과 검증** — 데이터 수집·라벨링, 모델 비교, 데모 앱/API 구현으로 기술 가능성을 빠르게 검증

### Representative Projects

- **이동형 IoT 공기청정기 WebRTC 실시간 연동** — 제품 디바이스와 모바일 앱을 WebRTC로 연결하고, 시그널링 서버·KMS 서버·Android/iOS 앱 연동을 구현했습니다.
- **RAG 기반 포트폴리오 AI 챗봇** — GitHub Pages 프론트엔드와 FastAPI/Socket.IO 백엔드를 분리하고, ChromaDB·reranking·vLLM 기반 RAG 응답 흐름을 구축했습니다.
